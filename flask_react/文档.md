新增 **图片裁剪 + 透视矫正功能**。

## 一、功能目标

当用户上传的文件是 **图片（jpg / jpeg / png）** 时，不直接进入处理流程，而是先进入 **图片裁剪页面**。

用户可以通过拖动 **四个角点** 选择裁剪区域，系统会自动进行 **透视变换（Perspective Transform）**，最终得到 **拉伸扭正后的矩形图片**。

该功能类似 **扫描文档 App 的裁剪功能**。

---

# 二、页面流程

用户上传图片后：

```
上传图片
   ↓
进入裁剪页面
   ↓
拖动四个角点调整裁剪区域
   ↓
点击「确认裁剪」
   ↓
执行透视变换
   ↓
生成矫正后的图片
   ↓
继续原有文件处理流程
```

---

# 三、裁剪页面 UI

页面中央显示上传的图片。

在图片上覆盖一个 **四边形裁剪框**：

特点：

* 四个角有 **拖动控制点**
* 用户可以拖动四个点改变裁剪区域
* 四个点自动连接成四边形
* 显示半透明遮罩

交互要求：

* 拖动点实时更新裁剪区域
* 限制点只能在图片范围内
* 默认自动检测一个矩形区域（可选）

页面底部按钮：

```
取消
确认裁剪
```

---

# 四、透视矫正算法

用户点击 **确认裁剪** 后：

获取四个角点坐标：

```
topLeft
topRight
bottomRight
bottomLeft
```

使用 **Perspective Transform（透视变换）**：

将四边形区域拉伸成 **标准矩形图片**。

最终得到：

```
扭正后的图片
```

效果类似：

```
倾斜文档  →  扫描后的正视图
```
